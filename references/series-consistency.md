# 系列风格一致性流程

仅当用户明确要求多张图片风格一致时执行。普通多图任务直接并发，不增加样稿确认。

## 1. 确认样稿

- 记录总张数、每张用途及提示词。先用 `--count 1` 生成代表图并展示，明确等待用户确认。
- 样稿计入总张数：总共 5 张时，确认 1 张后只提交剩余 4 张。样稿调整需要重新生成时，先确认额外生成授权。
- 未回复不是确认；只有用户明确授权自动选择样稿时，才可自行确认，并如实记录授权依据。
- 用户提供并明确认可现有样稿时直接采用；外部参考样稿不占用户要求新生成的张数。若总数已由生成样稿满足，不提交额外任务。

## 2. 保存统一规范

在本次输出目录保存 `series-plan.json`，不保存密钥或 Base64：

```json
{
  "sample_approved": true,
  "approval_note": "记录用户确认样稿或授权自动确认的原意，不能自行伪造",
  "total_count": 5,
  "generated_sample_count": 1,
  "sample_file": "sample.png",
  "reference_image": "sample.png",
  "model": "用户确认的完整模型 ID",
  "ratio": "9:16",
  "image_size": null,
  "style_prompt": "保留参考样稿的统一配色、背景、字体层级、主体外观和版式。仅变化允许变化的内容。",
  "palette": ["#FFFFFF", "#F2F2F2", "#202020"],
  "layout": "填写实际确认的标题、主体、说明位置、边距与阴影",
  "typography": "填写已确认的字体风格、粗细和层级",
  "subject": "填写时钟等主体需保持的形态、颜色和细节",
  "allowed_changes": ["每张标题", "功能文案", "明确允许变化的展示内容"]
}
```

- `style_prompt` 是实际传入每张请求的共同规范，必须包含本系列所有关键约束。其它结构化字段用于保存和对照，不会自动变成提示词。
- `image_size` 对独立尺寸模型填写已选的 `1K`、`2K` 或 `4K`，其它模型填 `null`。使用规范中的同一模型、比例和尺寸。
- 参考图使用本地绝对路径、相对规范文件的路径或公网 URL。不要使用临时且即将过期的地址；后续运行前仍需检查图床和参考图。
- 每条提示词固定相同的色值、背景、字体、版式、主体约束，并明确本张允许变化的部分。不要把上一张的新结果替换成后续共同参考，避免风格逐渐偏移。
- 当前 CLI 只接受一张参考图。原始产品参考与确认样稿都必须保留时，可先制作包含两者的清晰参考拼图并确认；不能静默丢弃用户参考图。模型不能接受必要参考图时停止并说明限制，不擅自换模型或改纯文生成。

## 3. 并发生成剩余图片

将每张不同内容保存为 `remaining-prompts.json` 字符串数组。已生成样稿不放入数组。

```powershell
.\scripts\run_007ai_image.ps1 --model <模型ID> --ratio 9:16 --count 4 --prompts-file "<目录>\remaining-prompts.json" --series-plan "<目录>\series-plan.json" --output-dir "<目录>" --concurrency 3 --format markdown
```

独立尺寸模型另加 `--image-size 4K` 等已确认参数。脚本验证样稿确认标记、张数预算、模型、比例和尺寸，在每张提示词前加同一 `style_prompt`，自动使用共同参考图。不要另传不同的 `--image`。

- `--count` 是本次待生成数量，不是包含已生成样稿的总数。
- 脚本的确认字段是执行凭据，不会自行判断用户是否真正确认；调用者必须根据真实对话填写。
- 并发请求受 `--concurrency` 限制，所有已确认提示词进入提交队列，不等待前张生成完成。服务端活跃任务额度不足时按额度分批调用。
- 一旦提交，记录批次路径，不因等待超时重新启动同一生成命令。使用 `--resume-batch "<目录>\batch-xxx.json"` 继续查询下载。

## 4. 汇总对照检查

成功图片下载后，使用可用的图片查看工具实际查看样稿及全部结果，必要时制作本地对照拼图。脚本只汇总任务状态，不具备自动视觉审核能力；没有查看图片时不能声称风格审核通过。

逐张检查并报告：

| 项目 | 检查内容 |
|---|---|
| 配色与背景 | 色值观感、明暗、背景纹理是否延续样稿 |
| 布局与字体 | 标题位置、留白、层级、粗细与风格是否统一 |
| 主体 | 时钟形态、刻度、指针、昼夜主题等是否与参考一致 |
| 文案 | 中文是否准确、无遗漏、无错字、未挤压或遮挡 |
| 输出 | 张数、比例、实际像素及文件是否符合要求 |

将样稿与后续结果按原计划顺序展示，列出失败和待处理项。发现差异先说明具体位置与修正建议，未经额外授权不自动重新生成。固定文字、标志与软件界面需要严格一致时，优先使用真实素材和固定排版模板；不得承诺 AI 输出完全一致。
